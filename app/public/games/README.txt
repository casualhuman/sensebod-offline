Sensebod Offline - games folder

Each game has a folder of its own here, named after the game's id in
src/features/games/catalogue.ts, with an index.html at its top:

    games/hextris/index.html
    games/tetris/index.html

Every folder keeps the project's licence file and a
SENSEBOD-OFFLINE-CHANGES.txt (where it came from, what was changed).
How to add one: app/docs/GAMES.md
