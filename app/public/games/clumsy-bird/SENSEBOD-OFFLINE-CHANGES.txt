Files changed
-------------
index.html
  - Loads the readable source files in js/ (in the order of the project's
    Gruntfile) instead of the minified build/clumsy-min.js.
  - Loads sensebod-offline-shim.js before every other script.
  - Removed: the Open Graph and Twitter Card tags (they held web addresses),
    the Google site verification tag, the robots and keywords tags, the Apple
    home-screen tags and icons, the favicon and the link to humans.txt.
  - Added a "Sound: on / off" button for touch screens.

index.css
  - The game font (data/css/gamefont.woff of the project) is now inside the
    style sheet as a data: address, and the .eot, .ttf and .svg copies are no
    longer used.
  - Removed the unused rules for the share buttons (#share, .google).
  - Added the style of the sound button.

js/game.js
  - The share.png and tweet.png pictures (Facebook / Twitter sharing) are no
    longer loaded. No sharing code was left in the game scripts.
  - The four sounds are no longer in the list that must load before the game
    starts. The three short sounds load in the background; the music loads
    when the first round starts. A sound that cannot load or cannot play is
    skipped (me.sys.stopOnAudioError = false, guarded me.audio.play), so sound
    can never stop the game from starting.
  - Only .mp3 sounds are used (me.audio.init("mp3")).
  - New functions: setupSound, loadSound, wantTheme, startTheme, toggleMute,
    showMuted. New setting game.music (false leaves the music out).

js/screens/play.js
  - The music no longer starts when the game loads (before any tap). It starts
    with a round, through game.wantTheme().

js/screens/title.js
  - Start text shortened and font size 20 changed to 44, so that it can be
    read on a 320px wide screen.

js/entities/HUD.js
  - The M key now calls game.toggleMute(), the same function as the button.

Files added
-----------
sensebod-offline-shim.js
  In-memory stand-ins for localStorage, sessionStorage and document.cookie
  when the browser refuses them (sandboxed frame). The best score is then
  kept only until the game is closed.
SENSEBOD-OFFLINE-CHANGES.txt (this file)
