# Sensebod round 13 — admin menu, generic uploads, animation uploads, Read type

Owner decisions:
1. **No "From WhatsApp" option** — there is no WhatsApp integration. Replace it everywhere with a plain **"Upload files"** source: files already on the phone (videos, audio and voice notes, documents PDF/Word, photos). Do NOT mention WhatsApp anywhere (no folder names, no "coming later" note). Delete references in copy.
2. **Phone admin needs the big ("jumbo") menu** that the laptop sidebar has. Design: every phone admin screen gets a top-right labelled **"Menu"** button (icon + word, ≥48px) AND a sticky bottom bar with 4 labelled tabs: Home · Add · Library · Menu. Tapping Menu opens a full-screen **jumbo menu** of large tiles (2 columns, each ≥96px tall, bold icon + label + one-line hint): Home, Add content, Library, Series and order, Learners and progress, Storage and backup, Settings, Sign out (secondary). Show which one is current. No hidden hamburger-only navigation. The bottom bar's main action stays above it where a screen has one.
3. **Animation uploads**: EasySTEM can make an animation and send it to the facilitator to upload. New source **"Upload an animation"** (icon: tapping hand + film/sparkle; becomes a **Try it** lesson). Accepts an animation package (.zip containing index.html, exported as HTML5 from an animation tool) — and H5P (.h5p) shown as "needs the H5P player on this bag — [ask EasySTEM]". After choosing the file, show checks with icon + words: "Opens without internet ✓", "Starts with index.html ✓", "Size: 18 MB ✓ (fine for old phones)", plus a failure example style ("Needs the internet to load fonts ✗ — ask EasySTEM for an offline version"). Then "Test as a learner" (phone frame preview) and go on to "Where does it go?". A plain animation video (MP4) is uploaded through Upload files and becomes **Watch**.
4. **Add the Read type**: icon = open book; learner button "Read"; tag line "Read · Lesson N"; facts: "[pages] pages" or "[minutes] min read", optional "Read along" (if the admin recorded their voice). Automatic type rule everywhere (admin and library): Video → Watch · Audio or voice note → Listen · Typed text, notes, PDF, Word, photos of notes → Read · Animation package → Try it · Questions → Check. Learner filters become **All · Watch · Listen · Read · Try it** (5 options; on phones wrap to two rows of big buttons or use a horizontally scrolling row with a visible "more" cue — choose the clearer; ≥48px targets).

Format/look: V3 light + Style B, as in ROUND10–12 briefs; `.dc.html` rules in ROUND2-BRIEF.md; phone boards fixed 390 wide, laptop fixed 1440 wide; root size == `$preview`; report exact sizes; < 220 KB; you may render to check. Backups of current boards are in `round12/` (read-only). Write only your assigned files; do not publish.
