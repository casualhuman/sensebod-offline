Lesson types · tag by what the learner does

5 tags. Icon + word, never colour alone. Same icons on cards, filters, headers and buttons.

Watch

Meaning: a video.

Main button

Watch video

With “You take part” (an interactive video) the button reads “Watch and answer”.

Listen

Meaning: audio. Read along is available.

Main button

Play audio

Facts row shows “Read along” so readers know the words are there.

Read

Meaning: text to read.

Main button

Read

Typed text, notes, PDF, Word or photos of notes. Facts: “[pages] pages” or “[minutes] min read”; “Read along” if the admin recorded their voice.

Try it

Meaning: an interactive animation.

Main button

Start

Always shows the “You take part” pill.

Check

Meaning: a quiz at the end of a series.

Main button

Start the quiz

One per series, after the last lesson. Not in the filter.

Automatic type rule · admin and library

The type is set from what is uploaded. The admin can see it on the review step; nobody picks it from a list.

  1. VideoMP4 and other video files, including a plain animation video.becomesWatch
  2. Audio or voice noteRecordings, songs, stories, voice notes.becomesListen
  3. Text and documentsTyped text, notes, PDF, Word, photos of notes.becomesRead
  4. Animation package.zip with index.html (HTML5), or .h5p with the H5P player.becomesTry it
  5. QuestionsWritten in “Add questions” at the end of a series.becomesCheck

Filter · above every lesson list

5 big buttons: All · Watch · Listen · Read · Try it. “All” is selected when the page opens. Selected = filled blue + aria-pressed; the icon and word stay. Check is not in the filter (one quiz per series, always last).

Phone · two rows, nothing hidden

Why two rows, not a scrolling row: every choice is visible at once, so nobody has to find a “more” cue or swipe.

Phone: 3 + 2 buttons, 64px tall, icon beside word, 8px gaps. Tablet and laptop: one row of 5, 64px. Progress in words stays below.

Example: Child protection, Lesson 4. A Watch lesson where the learner answers questions in the video.

  1. 1PictureA real scene from the lesson. Same height on every card.
  2. 2Type badgeRound icon on the picture edge. Same place on every card.
  3. 3Tag line“Watch · Lesson 4”. The tag word comes first, in bold.
  4. 4“You take part” pillOnly on lessons where the learner acts: taps, answers, chooses.
  5. 5State chipNot started, Started or Finished. Always icon + word.
  6. 6TitleThe lesson name, 24px, extra bold.
  7. 7Facts row[length] · Needs sound · Captions (Watch), Read along (Listen), [pages] pages (Read).
  8. 8Main buttonFull width. Repeats the action: here “Watch and answer”.

Data tag · one per lesson

The card, filter, header and button are all drawn from this tag. Nobody types the words by hand.

{
  "type": "watch|listen|read|try|check",
  "interactive": true,
  "captions": true,
  "readAlong": false,
  "needsSound": true,
  "length": null,
  "pages": null
}

Example above, one line: {"type":"watch|listen|read|try|check","interactive":true,"captions":true,"readAlong":false,"needsSound":true,"length":null,"pages":null}

typePicks the icon, the tag word and the main button: watch → “Watch video”, listen → “Play audio”, read → “Read”, try → “Start”, check → “Start the quiz”. Filter uses it too.
interactivetrue shows the “You take part” pill. On a Watch lesson the button becomes “Watch and answer”.
captionstrue adds “Captions” (CC icon) to the facts row. Watch lessons.
readAlongtrue adds “Read along” (book icon). Listen lessons, and Read lessons when the admin recorded their voice.
needsSoundtrue adds “Needs sound” (speaker icon). Watch and Listen.
lengthnull shows the placeholder “[length]”. Never invent a time. On Read lessons it shows “[minutes] min read”.
pagesRead lessons. null shows “[pages] pages”. Counted from the file, never typed.
