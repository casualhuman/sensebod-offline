The owner wrote: *"note that we are not doing a django app. if it includes anything like that. it's a node express. this is not for making specific backend tooling decision but tooling agnostics."* I applied this across `docs/system/`. `reviews/` was not touched, and the instructions file's generic Django sentence was left as it is.
