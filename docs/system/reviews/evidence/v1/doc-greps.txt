docs/system/SYNC.md:40:`bag_meta.epoch` (integer, starts at 1) is incremented by every restore. Order is compared as the pair `(epoch, seq)`. Reason: if a card dies after its later backup B2 (seq 500) reached the office, and the replacement is restored from an older B1 (seq 300), the new card's next changes reuse seq 301…; with the epoch they are `(2, 301…)` and sort after `(1, 500)`, so the office never mistakes new changes for old ones.
